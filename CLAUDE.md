## Design rules
- Before any UI, layout or CSS work, read design/DESIGN.md (the documented design system).
- Use only values defined as CSS custom properties in app/globals.css. If a new value is needed, add it as a token first and say so.
- The logo (public/logo.png) and the hero wordmark image stay exactly as they are unless explicitly asked otherwise.
- Screenshots for review go to design/screenshots/ (git-ignored).
- When anything about the design is ambiguous, ask instead of guessing.
